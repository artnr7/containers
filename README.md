Сборка основана на доккере чтобы у всех были одни и те же версии утилит.

# Сборка проекта

1. Собираете доккер образ:
```bash
make docker-build
```
2. Собираете проект:
```bash
make build
```

3. Запустить тесты:
```bash
make docker-test
```
4. Для отчета о покрытии:
```bash
make coverage
```

# Доп. команды
Посмотреть все команды:
```bash
make help
```
